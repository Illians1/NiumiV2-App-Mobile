# Niumi · La police

## Laquelle

**IBM Plex Sans**, validée le 9 octobre 2026. Trois graisses servent dans les maquettes :

| Graisse | Valeur | Nom courant du fichier |
| --- | --- | --- |
| Normal | 400 | Regular |
| Moyen | 500 | Medium |
| Demi-gras | 600 | SemiBold |

Pas d'italique. Les chiffres ont tous la même largeur sans réglage.

La police est à embarquer dans l'app sur iPhone et sur Android, pour que l'app ait la même police sur les deux.

## Où prendre les fichiers

Les fichiers ne sont pas dans ce dossier. Ils sont à télécharger depuis le dépôt officiel d'IBM :

- [github.com/IBM/plex](https://github.com/IBM/plex), page [des versions](https://github.com/IBM/plex/releases)

Le fichier LISEZ-MOI de ce dépôt indique de télécharger les archives depuis la page des versions. Les formats proposés n'ont pas été vérifiés : il faut y prendre les fichiers destinés à être installés dans une application, dans les trois graisses ci-dessus.

## Ce que demande la licence

IBM Plex Sans est distribuée sous la **SIL Open Font License 1.1**.

Ce qu'elle permet :

- Inclure la police dans une app, même payante.
- L'app n'a pas à être open source.

Ce qu'elle demande :

- Joindre à l'app la mention de droit d'auteur, la notice de licence et le texte de la licence.
- Ne pas vendre la police seule.

Pour Niumi, cela donne la page ouverte par le lien « Licences » de la page À propos. Elle doit afficher la mention « Copyright IBM Corp. » et le texte de la licence. Cette page n'est pas encore dessinée (voir `POINTS-OUVERTS.md`, M3).

`LICENCE-IBM-Plex-Sans.txt` est le fichier de licence livré avec le paquet Fontsource d'IBM Plex Sans, version 5.3.0. Il est joint pour information. Le texte à afficher dans l'app doit être celui du fichier de licence livré avec les fichiers de police réellement téléchargés.
